FOLDER KHUSUS BACKGROUND (GAMBAR & VIDEO)
=========================================

Taruh semua file gambar (.jpg, .jpeg, .png, .webp, .gif, .bmp, .svg) dan video (.mp4, .webm, .ogg, .mov, .m4v) untuk background di folder ini (`public/backgrounds/`).

Sistem secara otomatis membaca semua file dari folder ini saat aplikasi dijalankan atau di-build (baik di mode lokal maupun saat di-hosting ke Vercel / GitHub), tanpa perlu mengubah atau menulis gambar/video ke dalam kode.
